How we check

  1. We first confirm the website exists, using Google's public DNS lookup.
  2. We then check the link against Google Safe Browsing, a list of sites reported for malware, phishing, and unwanted software.

This only catches threats Google already knows about, so a brand-new scam can pass. A "safe" result is never a guarantee.
